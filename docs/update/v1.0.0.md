# Prism ROS Adapter 1.0.0 update notes

Updated release date: 2026-09-04

## Compatibility

- ROS Adapter release tag: `v1.0.0`
- Prism SDK: `1.0.0`
- Supported device Agent: `1.0.0`
- Qualified sensor-board: `0.4.25`
- USB protocol: `1`

The adapter pins Prism SDK 1.0.0 as its Git submodule and requires the matching
Agent 1.0.0 runtime. Its ROS packages also remain version 1.0.0.

## Updated release contents

- Linux x86-64 builds for ROS 1 Noetic and ROS 2 Foxy, Humble, Jazzy, Kilted,
  Lyrical, and Rolling, using one Ubuntu 20.04-baseline `.so` with OpenSSL
  statically embedded.
- Linux ARM64 builds for the same ROS matrix.
- ROS 2 Foxy support on Ubuntu 20.04.
- Native CI coverage for every supported ARM64 ROS/Ubuntu combination.
- One shared `runtime/ros/linux-x64` SDK prefix for every supported x86-64
  Ubuntu release.
- A portable ARM64 static SDK integration that resolves Threads, libusb,
  OpenSSL, libstdc++, and glibc in each target ROS environment.
- Mid-360/Mid-360S point clouds published at 10 Hz as
  `sensor_msgs/PointCloud2`, including `uint32 offset_time` in nanoseconds.
- USB protocol 1 and the documented ROS topic/service interfaces.

## Upgrade

Update the repository and its pinned SDK submodule together:

```bash
git fetch --tags origin
git checkout v1.0.0
git submodule sync --recursive
git submodule update --init --recursive
```

Remove previous ROS workspace build/install/log directories, then rebuild for
the target ROS distribution. No device firmware update is required when Agent
1.0.0 and sensor-board 0.4.25 are already installed.
