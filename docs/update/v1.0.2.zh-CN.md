# Prism ROS Adapter 1.0.2 更新说明

发布日期：2026-09-04

## SDK 依赖

Adapter 现在将 Prism SDK 分发版本 `1.0.2` 固定为 Git submodule。该分发版本
提供从 SDK 1.0.0 源码基线编译的 Host SDK 运行时/ABI `1.0.0`，并继续要求设备端
Agent `1.0.0` 和 USB 协议 `1`。

Adapter 有意保留
`find_package(PrismUsbSdk 1.0.0 EXACT CONFIG REQUIRED)`：这里的 1.0.0 是
运行时兼容版本，而 1.0.2 是二进制分发版本。

## 1.0.2 改动

- 新增 ROS 1 Noetic 以及 ROS 2 Foxy、Humble、Jazzy、Kilted、Lyrical、
  Rolling 的 Linux ARM64 构建。
- 新增 Ubuntu 20.04 上的 ROS 2 Foxy 支持。
- CI 新增全部受支持 ARM64 ROS/Ubuntu 组合的原生构建验证。
- 新增通用 ARM64 静态 SDK 集成，在各目标 ROS 环境中解析 Threads、libusb、
  OpenSSL、libstdc++ 和 glibc。
- x86-64 继续按 Ubuntu 版本选择对应动态 SDK 前缀。
- Mid-360/Mid-360S 点云以 10 Hz 发布为 `sensor_msgs/PointCloud2`，并包含纳秒
  `uint32 offset_time` 字段。
- 协议版本保持为 1，现有 ROS topic/service 接口不变。

## 升级方法

同时更新 Adapter 仓库及其固定的 SDK submodule：

```bash
git pull --ff-only origin master
git submodule sync --recursive
git submodule update --init --recursive
```

删除旧 ROS workspace 的 build/install/log 目录后，针对目标 ROS 版本重新编译。
设备已经运行 Agent 1.0.0 时，不需要更新设备固件。
