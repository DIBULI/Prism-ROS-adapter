# Prism ROS Adapter 1.0.0 更新说明

更新发布日期：2026-09-04

## 兼容关系

- ROS Adapter Release Tag：`v1.0.0`
- Prism SDK：`1.0.0`
- 支持的设备 Agent：`1.0.0`
- 已验证的 sensor-board：`0.4.25`
- USB 协议：`1`

Adapter 将 Prism SDK 1.0.0 固定为 Git submodule，并要求匹配的 Agent 1.0.0
运行时。全部 ROS package 的版本也保持为 1.0.0。

## 更新后的发布内容

- ROS 1 Noetic 以及 ROS 2 Foxy、Humble、Jazzy、Kilted、Lyrical、Rolling
  的 Linux x86-64 构建，统一使用 Ubuntu 20.04 ABI 基线且静态包含 OpenSSL
  的一份 `.so`。
- 同一 ROS 矩阵的 Linux ARM64 构建。
- Ubuntu 20.04 上的 ROS 2 Foxy 支持。
- 全部受支持 ARM64 ROS/Ubuntu 组合的原生 CI 验证。
- 全部受支持 x86-64 Ubuntu 版本共用一份 `runtime/ros/linux-x64` SDK 前缀。
- 通用 ARM64 静态 SDK 集成，在各目标 ROS 环境中解析 Threads、libusb、
  OpenSSL、libstdc++ 和 glibc。
- Mid-360/Mid-360S 点云以 10 Hz 发布为 `sensor_msgs/PointCloud2`，并包含纳秒
  `uint32 offset_time` 字段。
- USB 协议保持为 1，并保留文档中的 ROS topic/service 接口。

## 升级方法

同时更新 Adapter 仓库及其固定的 SDK submodule：

```bash
git fetch --tags origin
git checkout v1.0.0
git submodule sync --recursive
git submodule update --init --recursive
```

删除旧 ROS workspace 的 build/install/log 目录后，针对目标 ROS 版本重新编译。
设备已经运行 Agent 1.0.0 和 sensor-board 0.4.25 时，不需要更新设备固件。
