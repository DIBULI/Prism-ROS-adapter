# Prism ROS Adapter v1.2.0

## 本版本包含的功能

以下汇总 1.2.0 的累计能力，包括此前已有并继续保留的功能。

- ROS1/ROS2 相机图像/元数据、板载 IMU 和雷达话题。
- 设备/版本/状态查询、网络和 Wi-Fi 配置、显式校时。
- 采集启停、USB 和 RK-local 接入。
- 单个相机或传感器缺失时，继续发布其余正常数据。
- 改善显式校时后开始采集的可靠性。
- 支持接收机原生 GNSS/RTK 位置、精度和状态，以及 CORS 配置、RTK 启停；移除旧 raw/smoothed 导航接口。
- 新增独立雷达待机/唤醒，完善 MID360/MID360S/XT32 点云字段。
- 支持统一自动曝光。
- 同步 SDK 和使用文档，区分内部时间对齐与 UTC 有效性；最新对齐和曝光行为需配套固件。

配合 SDK/Agent **1.2.0** 和对应 **0.4.27** 固件使用。需重新编译 ROS 工作空间及消息/服务，不能混用旧 1.1.0 接口。
ROS 仅提供实时采集与控制，不提供离线数据集下载或固件升级服务。本次文档整理不修改 ROS 接口。

源码包包含所需 SDK 头文件和库；安装不会自动刷写设备、开始采集或连接 CORS。
