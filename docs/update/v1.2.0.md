# Prism ROS Adapter v1.2.0

## What's included

Cumulative 1.2.0 functionality, including features retained from earlier releases:

- ROS1/ROS2 camera images/metadata, onboard IMU and LiDAR topics.
- Device/version/status, network/Wi-Fi configuration and explicit clock synchronization.
- Acquisition controls and USB or RK-local access.
- Continue publishing healthy sensors when an individual camera or sensor is missing.
- Improve acquisition reliability after explicit clock synchronization.
- Support receiver-native GNSS/RTK positions, accuracy/status, CORS configuration
  and RTK start/stop; retire the previous raw/smoothed navigation interfaces.
- Add independent LiDAR standby/wake and richer MID360/MID360S/XT32 point metadata.
- Support unified automatic exposure.
- Refresh the SDK dependency and documentation, including internal time alignment
  versus UTC validity. The latest alignment/exposure behavior needs matching firmware.

Use SDK/Agent **1.2.0** and matching **0.4.27** firmware. Rebuild ROS workspaces
and generated messages/services; old 1.1.0 interfaces are not interchangeable.
ROS remains a live acquisition/control adapter, without offline dataset download
or firmware-upgrade services. This documentation refresh does not change ROS APIs.

The source archive includes the required SDK headers and libraries. Installing
it does not flash firmware or start capture/CORS.
