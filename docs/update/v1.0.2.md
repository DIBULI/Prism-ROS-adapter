# Prism ROS Adapter 1.0.2 update notes

Release date: 2026-09-04

## SDK dependency

The adapter now pins Prism SDK distribution `1.0.2` as its Git submodule. That
distribution packages the established Host SDK runtime/ABI `1.0.0`, compiled
from the SDK 1.0.0 source baseline, and still requires device Agent `1.0.0` and
USB protocol `1`.

The adapter intentionally keeps
`find_package(PrismUsbSdk 1.0.0 EXACT CONFIG REQUIRED)`: this is the runtime
compatibility version, while 1.0.2 is the binary distribution version.

## Changes in 1.0.2

- Added Linux ARM64 builds for ROS 1 Noetic and ROS 2 Foxy, Humble, Jazzy,
  Kilted, Lyrical, and Rolling.
- Added ROS 2 Foxy support on Ubuntu 20.04.
- Added native CI coverage for every supported ARM64 ROS/Ubuntu combination.
- Added a portable ARM64 static SDK integration that resolves Threads, libusb,
  OpenSSL, libstdc++, and glibc in each target ROS environment.
- Kept x86-64 builds mapped to Ubuntu-specific shared SDK prefixes.
- Publishes Mid-360/Mid-360S point clouds at 10 Hz as
  `sensor_msgs/PointCloud2`, including `uint32 offset_time` in nanoseconds.
- Preserves protocol version 1 and the existing ROS topic/service interfaces.

## Upgrade

Update the repository and its pinned SDK submodule together:

```bash
git pull --ff-only origin master
git submodule sync --recursive
git submodule update --init --recursive
```

Remove previous ROS workspace build/install/log directories, then rebuild for
the target ROS distribution. No device firmware update is required when Agent
1.0.0 is already installed.
