# Prism ROS Adapter 1.0.1 update notes

Release date: 2026-09-04

## Compatibility

- ROS Adapter release tag: `v1.0.1`
- Prism SDK: `1.0.0`
- Supported device Agent: `1.0.0`
- Qualified sensor-board: `0.4.25`
- USB protocol: `1`

## Changes since 1.0.0

- LiDAR streaming is disabled by default.
- ROS 1 and ROS 2 launch files now take the LiDAR model and network settings
  directly from their YAML configuration files without overriding them with
  launch-argument defaults.
- Optional startup network configuration reads the saved device state first,
  writes only when values differ, and rejects invalid IPv4 values or an
  unverified save before streams start.
- Camera capture uses `camera_present_mask` so non-contiguous populated camera
  slots do not cause an empty-slot capture timeout.
- A bare ROS 2 `colcon build` can automatically locate the matching bundled
  x86-64 or ARM64 Prism SDK runtime when no SDK prefix is supplied.

## Upgrade

```bash
git fetch --tags origin
git checkout v1.0.1
git submodule sync --recursive
git submodule update --init --recursive
```

Remove previous ROS workspace build/install/log directories, then rebuild for
the target ROS distribution. No device firmware update is required when Agent
1.0.0 and sensor-board 0.4.25 are already installed.
