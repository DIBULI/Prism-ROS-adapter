# Prism ROS Adapter 1.0.1 更新说明

发布日期：2026-09-04

## 兼容关系

- ROS Adapter Release Tag：`v1.0.1`
- Prism SDK：`1.0.0`
- 支持的设备 Agent：`1.0.0`
- 已验证的 sensor-board：`0.4.25`
- USB 协议：`1`

## 相比 1.0.0 的改动

- LiDAR 数据流默认关闭。
- ROS 1 和 ROS 2 launch 文件直接从各自的 YAML 配置读取 LiDAR 型号与网络
  参数，不再由 launch 参数默认值覆盖。
- 支持可选的启动时 LiDAR 网络配置：先读取设备已保存的配置，仅在参数不一致
  时写入；IPv4 参数无效、设备拒绝或保存结果无法确认时，在数据流启动前报错退出。
- 相机采集改用 `camera_present_mask`，非连续相机槽位不会再因请求空槽位而导致
  capture enable 超时。
- 未指定 SDK 路径时，ROS 2 的 `colcon build` 可自动定位仓库内匹配的 x86-64
  或 ARM64 Prism SDK runtime。

## 升级方法

```bash
git fetch --tags origin
git checkout v1.0.1
git submodule sync --recursive
git submodule update --init --recursive
```

删除旧 ROS workspace 的 build/install/log 目录后，针对目标 ROS 版本重新编译。
设备已经运行 Agent 1.0.0 和 sensor-board 0.4.25 时，不需要更新设备固件。
