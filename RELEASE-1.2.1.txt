Build ROS2 Jazzy (inside the extracted archive):
  source /opt/ros/jazzy/setup.bash
  bash scripts/verify_sdk_submodule.sh linux-x64
  colcon build --base-paths ros2_ws/src --build-base build-jazzy \
    --install-base install-jazzy --cmake-args \
    -DCMAKE_BUILD_TYPE=Release -DPRISM_TRANSPORT=usb
  source install-jazzy/setup.bash
  python3 scripts/verify_navigation_ros2.py

Standard ROS2 build dependencies must already be installed. CMake resolves the
bundled SDK from third_party/Prism-SDK/runtime/ros/linux-x64. Check README.md
and launch files for normal node use. Merely building does not open a device.

ROS1 Noetic: source and exact SDK dependency are updated to 1.2.1. Build within
your existing Noetic environment using the repository instructions; do not treat
the Jazzy build as a Noetic binary or as proof of Noetic runtime validation.
